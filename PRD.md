Product Requirement Document (PRD)Nama Produk: Website Modul Pembelajaran Interaktif: Limit FunctionInstitusi: Universitas Teknokrat Indonesia (Fakultas Teknik dan Ilmu Komputer)   Teknologi: HTML5, CSS3 (Tailwind CSS + Custom CSS), JavaScript (ES6), KaTeX, HTML5 Canvas APIVersi: 1.0.0Bahasa: Indonesia1. Latar Belakang & Tujuan1.1 Latar BelakangTopik Limit Function merupakan materi dasar dalam Kalkulus. Mahasiswa sering kali mengalami kendala dalam memahami konsep abstrak seperti pendekatan nilai limit secara intuitif, definisi formal epsilon-delta ($\varepsilon - \delta$), serta pemilihan metode penyelesaian yang tepat untuk menghindari bentuk tak tentu seperti $\frac{0}{0}$.   1.2 Tujuan ProdukMenyediakan media pembelajaran digital yang interaktif dan responsif bagi mahasiswa.Memisahkan struktur kode secara rapi ke dalam tiga berkas utama (index.html, styles.css, script.js) agar mudah dikelola (maintainable).Menyajikan visualisasi grafik interaktif menggunakan HTML5 Canvas dan rumus matematika presisi menggunakan KaTeX.2. Arsitektur & Struktur Berkas (Tech Stack)Proyek ini dibangun menggunakan arsitektur Single Page Application (SPA) sederhana berbasis client-side, dibagi menjadi tiga berkas terpisah:Plaintextmodul-limit/
├── index.html     # Berkas struktur halaman dan layout utama
├── styles.css     # Berkas pengaturan gaya visual, animasi, dan komponen UI
└── script.js      # Berkas logika interaktif (Tab switcher, Canvas Epsilon-Delta, Simulator, Kuis)
HTML (index.html): Menggunakan semantic HTML serta memuat CDN pendukung seperti Tailwind CSS, Font Awesome, dan KaTeX.CSS (styles.css): Mengatur transisi animasi tab aktif, kustomisasi scrollbar, serta penataan gaya responsif.JavaScript (script.js): Menangani logika perpindahan tab, perhitungan rumus dinamis, rendering visualisasi grafik 2D pada Canvas, serta validasi kuis otomatis.3. Spesifikasi Fungsional Berdasarkan Modul3.1 Navigasi Header & Layout Utama (index.html)Identitas Institusi: Menampilkan logo/akronim Universitas Teknokrat Indonesia serta keterangan Fakultas Teknik dan Ilmu Komputer.   Navigasi Tab Interaktif: Pengguna dapat berpindah antar bagian materi secara instan tanpa memuat ulang halaman (reload):Intuisi & Grafik   Definisi Presisi ($\varepsilon - \delta$)   Teorema Limit   Metode & Contoh   Kuis Interaktif   3.2 Modul 1: Intuisi & Grafik (index.html & script.js)Tabel Pendekatan Nilai: Menampilkan tabel ilustrasi nilai $f(x) = \frac{x^2-1}{x-1}$ saat $x$ mendekati $1$ dari sisi kiri dan kanan.   Simulator Uji Pendekatan:Fitur interaktif di mana pengguna dapat memilih fungsi (misal: fungsi pecahan atau fungsi sepotong/piecewise) dan mengubah nilai $x$ secara dinamis.   Menampilkan hasil evaluasi $f(x)$ secara langsung beserta analisis apakah limit tersebut ada atau tidak.   3.3 Modul 2: Definisi Presisi $\varepsilon - \delta$ (index.html & script.js)Definisi Formal: Menjelaskan syarat formal limit $\lim_{x \to c} f(x) = L$.   Visualisator Canvas Interaktif:Menyediakan slider input toleransi $\varepsilon$ (Epsilon).   Secara otomatis menghitung nilai $\delta = \varepsilon / 3$.   Menggambar grafik fungsi linear $f(x) = 3x - 7$ beserta pita interval toleransi pada elemen <canvas> secara real-time.   3.4 Modul 3: Teorema Limit (index.html)Menyajikan 9 Aturan Utama Limit (Theorem A) dalam bentuk kartu informasi (cards) yang bersih dan terstruktur:   Aturan Konstanta ($\lim_{x \to c} k = k$)   Aturan Identitas ($\lim_{x \to c} x = c$)   Aturan Kelipatan Konstanta   Aturan Penjumlahan & Pengurangan   Aturan Perkalian & Pembagian   Aturan Pangkat & Akar   3.5 Modul 4: Metode Penyelesaian & Contoh (index.html & script.js)Peringatan Bentuk Tak Tentu: Memberikan catatan agar menghindari bentuk $\frac{0}{0}$, $\frac{\infty}{\infty}$, dan $\infty - \infty$.   Tiga Metode Utama:Substitusi Langsung   Pemfaktoran (Factor)   Perkalian Sekawan (Conjugate)   Panel Solusi Langkah-demi-Langkah: Tombol interaktif untuk menampilkan modal pembahasan rinci step-by-step untuk setiap metode.   3.6 Modul 5: Kuis Interaktif (index.html & script.js)Berisi 3 soal pilihan ganda evaluasi mandiri terkait materi limit.   Fitur Penilaian Otomatis: Tombol "Submit Jawaban" akan menghitung skor akhir (skala 0–100) dan memunculkan ulasan status benar/salah beserta penjelasan singkat di setiap soal.   4. Persyaratan Non-Fungsional (NFR)Kompatibilitas & Performa: Berjalan dengan lancar di semua peramban modern (Chrome, Firefox, Edge, Safari) tanpa memerlukan instalasi tambahan di sisi server.Desain Responsif: Tata letak menggunakan utilitas Tailwind CSS agar menyesuaikan dengan baik pada layar perangkat mobile, tablet, maupun komputer desktop.   Keterbacaan Matematika: Menggunakan pustaka KaTeX agar seluruh persamaan dan simbol kalkulus ter-render dengan format huruf miring dan bentuk pecahan matematis yang profesional.
